# TigerLake Terminal Site

TigerLake is a unique web-based terminal experience built to showcase my GitHub projects, social links, and real-time integration with Discord and Spotify. The site is styled using **shadcn**, **Radix UI**, **Lucide Icons**, and **Framer Motion** for smooth animations and an interactive feel.


https://github.com/user-attachments/assets/6041f2ac-de18-4896-9384-02b575b531f7


## Features

- **Terminal Simulation**  
  The site offers a terminal interface where visitors can use commands to navigate and explore different sections:
  - `projects/repos` → View my GitHub repositories.
  - `about/info` → Learn about me.
  - `skills/tech` → See my skills and technologies.
  - `socials` → Social media links.
  - `cls/clear` → Clear the terminal.
  - `theme or theme light/dark` → Toggle between light and dark themes.
  - `music/np` → Show the currently playing song.
  - `date/time` → Display the current date and time.
  - `welcome/hi` → A friendly greeting.

- **Real-Time Spotify and Discord Integration**  
  Using **Lanyard webhooks**, the site fetches my current Discord status and profile picture, along with displaying the song I'm playing on Spotify in real time.

- **GitHub Repositories**  
  The most starred repositories are highlighted with a brief description, star count, and the main technologies used.

- **Social Links**  
  Direct links to my Discord, GitHub, and X (formerly Twitter), providing a quick way to connect with me.

## Tech Stack

- **Next.js** (with TypeScript)
- **Shadcn** for UI components
- **Radix UI** for accessibility-focused components
- **Lucide Icons** for beautiful, customizable icons
- **Framer Motion** for smooth animations
- **Lanyard** for real-time Discord and Spotify updates

# Installation and Setup

To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Trixzyy/terminal-site.git
   ```

2. Install dependencies:
   ```bash
   bun i
   ```

3. Run the development server:
   ```bash
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the site in action.
